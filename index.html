Featured Case Study

ops-report-ai

CoopNorte · Cooperative Financial Institution (Fictitious)

Modernizing a compliance reporting system under strict regulatory constraints.

Business Context

CoopNorte processed end-of-day financial reports through a monolithic batch system prone to failures under peak load. Regulatory audits required tamper-proof audit trails and role-based access to sensitive reporting data — capabilities the existing architecture couldn't provide.

Architecture Challenges

  • Tight coupling between report generation, storage and delivery layers
  • No identity boundaries — any internal service could access any report
  • Missing fitness functions: no automated checks for latency SLOs or coupling regression

Architecture Decision Records

ADR-001 Hexagonal Architecture as structural pattern Accepted
Context

Domain logic was bleeding into infrastructure layers (DB queries in controllers, framework coupling in business rules).

Decision

Adopt Ports & Adapters to isolate domain from infrastructure. All external dependencies communicate through defined interfaces.

Consequences

Higher initial complexity; decoupled domain enables independent testing and future adapter swaps without domain changes.

ADR-002 BFF pattern for web and mobile API surfaces Accepted
Context

A single generic API was being consumed by both the compliance web portal and a mobile app, leading to over-fetching and fragile versioning.

Decision

Introduce a Backend-for-Frontend layer per client type. Each BFF owns its aggregation logic and data contract.

Consequences

Increases deployment units; removes shared-API coupling and allows independent evolution of each client experience.

ADR-003 OIDC/PKCE with BFF session management Accepted
Context

Sensitive financial reports required identity-aware access control. Storing tokens in the browser posed XSS risk.

Decision

Use OIDC Authorization Code + PKCE flow with token storage in BFF session (HttpOnly cookies). Browser never holds tokens.

Consequences

Adds BFF complexity; eliminates token theft attack surface from browser-side JS.
